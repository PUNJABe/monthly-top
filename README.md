# Monthly Top

This repository contains the Monthly Top web app, a pay-to-rank listing and leaderboard platform built with Node.js and Express.

## Project overview

Monthly Top lets people submit links, profiles, tools, apps, and websites and then pay to boost those entries higher in monthly category rankings. It works well for product discovery boards, AI tool list pages, creator directories, startup showcases, and public rankings.

## Included app

The source code for the project is inside the `monthlytop/` folder.

## Quick start

```bash
cd monthlytop
npm install
npm start
```

Then open:

```text
http://localhost:3000
```

## Features

- category-based rankings
- monthly leaderboard resets
- pay-to-rank boosts
- admin moderation tools
- demo mode and Stripe-ready live mode
- SQLite data storage
- static public pages and forms

## Deployment

This is a backend-powered Node app, so it should be deployed on a host that supports Express server apps such as Azure App Service, Render, Railway, or a VPS.
